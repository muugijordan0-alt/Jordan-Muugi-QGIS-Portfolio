# Land Use / Land Cover Classification

## Objective
Classify land into categories using satellite imagery.

## Tools
- QGIS
- Sentinel-2 data

## Methodology
1. Load satellite imagery into QGIS  
2. Clip the study area  
3. Perform classification  
4. Categorize land:
   - Urban
   - Vegetation
   - Water
   - Bare land  

## Output
- Land use map
